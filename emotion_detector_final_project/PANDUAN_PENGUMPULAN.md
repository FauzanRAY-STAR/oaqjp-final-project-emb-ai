## Langkah GitHub

1. Buka repositori asli `https://github.com/ibm-developer-skills-network/oaqjp-final-project-emb-ai` dan tekan **Fork**.
2. Pastikan nama fork `oaqjp-final-project-emb-ai`.
3. Unggah file di proyek ini ke fork tersebut, pertahankan struktur `EmotionDetection/`, `templates/`, dan `static/`.
4. Ubah judul README menjadi `# Final Project`, lalu pastikan repositori terlihat **Public**.
5. Buka tautan file di repositori milikmu, lalu salin URL lengkap ke kolom URL.

**Penting:** Saya tidak memiliki akses untuk membuat fork GitHub atas nama akunmu dan tidak membuat tangkapan layar palsu. Dua URL di atas baru valid setelah `<USERNAME>` diganti dan file benar-benar di-commit ke repositorimu.
